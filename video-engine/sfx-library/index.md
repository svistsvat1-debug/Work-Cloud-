# SFX library (base set, reused in every video)

Sources live in `raw/` as small MP3s (committed). Run `python tools/sfx_prep.py` to rebuild the 48 kHz stereo WAVs (not committed).
Generated once with ElevenLabs Sound Effects (`eleven_text_to_sound_v2`, 1 take each, ~17 credits each) on 2026-11-11, except `soft_whoosh` and `counter_roll`, which come from `cartoon-shorts/sfx-library` (also ElevenLabs).
**Rule:** max 5 NEW sounds per video, only for unique moments; list them for the owner first.

| file | sound | prompt (short) |
|---|---|---|
| marker_squeak_short | one quick marker stroke on a whiteboard | short squeak of a felt marker, one line |
| marker_squeak_long | marker writing a word, several strokes | marker writing a word, ~2 s |
| marker_tap | marker tip dot | single soft tap |
| pop | soft cartoon pop | icon popping on screen |

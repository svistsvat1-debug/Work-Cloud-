# Voice Studio

Програма для озвучки: вставляєш текст і отримуєш природний чоловічий голос.
**Мови:** англійська, німецька, іспанська, китайська. Можна працювати з комп'ютера і з телефону.
Усе працює на твоєму комп'ютері: без акаунтів, підписок, API-ключів і лімітів на кількість хвилин.

- **На виході:** WAV (для монтажу), MP3 і субтитри `.srt` для YouTube.
- **Свій голос:** мікс двох голосів у потрібній пропорції (англійська, китайська).
- **Швидкість:** на звичайному ноутбуці приблизно 3 хвилини озвучки за 1 хвилину роботи. Відеокарта не потрібна.

## Голоси і ліцензії

Усі моделі дозволяють комерційне використання, тому озвучку можна монетизувати.

|---|---|---|---|

| Іспанська | Alex (Іспанія) | Kokoro-82M v1.0 | Apache 2.0 |
| | Dave (Іспанія) | Piper, датасет davefx | CC0 |
| | Ald (Мексика) | Piper, датасет ald | Unlicense (суспільне надбання) |
| Китайська | 10 голосів різного тембру | Kokoro-82M v1.1-zh | Apache 2.0 |

Найприродніше звучать англійська й китайська (Kokoro). Німецька та іспанські голоси Piper простіші, але чисті й зрозумілі.

## Запуск

Один раз потрібен **Python 3.12** → https://www.python.org/downloads/
(на Windows під час встановлення постав галочку **"Add python.exe to PATH"**).
Китайська працює лише на Python 3.10–3.12, тому бери саме 3.12.

| Система | Що зробити |
|---|---|
| Windows | двічі клікнути `start.bat` |
| macOS | двічі клікнути `start.command` (якщо macOS блокує: правий клік → «Відкрити») |
| Linux | `bash start.command` |

Перший запуск триває кілька хвилин: програма ставить компоненти й завантажує англійську модель (~350 MB).
Моделі інших мов завантажуються самі, коли вперше обираєш мову: німецька ~116 MB, іспанська ~68 MB на голос, китайська ~365 MB.
Далі все працює без інтернету. Браузер відкриється сам на `http://127.0.0.1:8765`.
Щоб вимкнути програму, закрий чорне вікно консолі.

**Брандмауер.** На першому запуску Windows (або macOS) спитає, чи дозволити Python доступ до мережі.
Натисни **«Дозволити»** для приватних мереж. Без цього телефон не підключиться, а на комп'ютері програма все одно працюватиме.

## З телефону

1. На комп'ютері натисни **«📱 З телефону»** (вгорі справа).
2. Наведи камеру телефону на QR-код і відкрий посилання. Телефон має бути в тій самій Wi-Fi мережі.
3. Додай сторінку на головний екран («Поділитися» → «На екран Додому»), і вона відкриватиметься як застосунок.

На телефоні працює все: вставка тексту, вибір голосу, озвучка, прослуховування і завантаження файлів.
Озвучку виконує комп'ютер, тому він має бути увімкнений і з запущеною програмою.
Посилання з QR-коду містить секретний ключ: без нього інші пристрої в мережі програму не відкриють.

## Як користуватись

1. Обери мову вкладкою вгорі й встав текст. Порожній рядок між абзацами дає довшу паузу.
2. Обери голос і натисни ▶, щоб прослухати.
3. За бажання увімкни **«Свій унікальний голос»**: мікс двох голосів у вибраній пропорції.
   Запам'ятай комбінацію (наприклад, Michael 60% + Fenrir 40%) і використовуй її в усіх відео. Так у каналу буде впізнаваний голос, який не збігається з жодним стандартним.
4. **Озвучити** (або Ctrl+Enter). Готові файли лежать у папці `output/` і в списку «Останні озвучки».

Для кожної мови запам'ятовується свій голос і своя чернетка тексту. Зручно, якщо робиш те саме відео кількома мовами.

## Щоб звучало максимально по-людськи

- **Пунктуація керує інтонацією.** Кома дає коротку паузу, крапка дає паузу й спад інтонації, `?` і `!` теж звучать.
- **Короткі речення** звучать природніше за довгі.
- **Швидкість 0.95–1.05** найприродніша для оповіді. 1.1+ підходить для динамічних Shorts.
- **Словник вимови** (у бічній панелі): якщо слово читається неправильно, додай рядок `слово = як читати`,
  наприклад `SaaS = sass`, `Nguyen = win`. Словник спільний для всіх мов і зберігається у `pronunciations.json`.
- Програма сама виправляє типові проблеми:
  - EN: `$1,500` → "one thousand five hundred dollars", `in 2026` → "twenty twenty-six", `vs.`, `e.g.`, `#1`, `10x`;
  - DE: `5 €`, `$5`, `z.B.`, `d.h.`, `bzw.`, `usw.`, `Nr.`;
  - ES: `1.500 €` → "mil quinientos euros", `$5`, `p. ej.`, `EE. UU.`, `Sr.`/`Sra.`;
  - ZH: числа, відсотки й англійські слова всередині китайського тексту.

  Також прибирає markdown-розмітку (`**`, `#`, маркери списків), якщо текст скопійовано з ChatGPT.
- Якщо в тексті трапляться літери іншої мови (наприклад, кирилиця в англійському тексті), програма попередить і не зіпсує озвучку.
- Відома слабкість англійської: омографи на кшталт *read* (минулий час) іноді читаються як "reed".
  Тоді заміни слово у тексті або допиши його у словник вимови.

## Авторські права і YouTube

**Голос:**
- Ліцензії всіх моделей (таблиця вище) дозволяють комерційне використання без роялті й без обов'язкового згадування у відео.
- Голоси не є клонами відомих людей. Датасети голосів Piper опубліковані як суспільне надбання (CC0 / Unlicense).
  **Не клонуй** голоси реальних людей (блогерів, акторів) без їхньої згоди: це вже юридичний ризик.

**Монетизація YouTube:**
- AI-озвучка сама по собі не заборонена.
- Монетизацію знімають за **«inauthentic content»**: масові шаблонні відео з мінімальними відмінностями.
  Головне — власний сценарій, своя подача і цінність у кожному відео, а не тільки голос.
- Позначка «Altered or synthetic content» у YouTube Studio потрібна для реалістичного контенту, що може ввести в оману
  (наприклад, голос або обличчя реальної людини). Якщо сумніваєшся, постав позначку.
- Музика, футаж і картинки у відео — окреме питання ліцензій, не пов'язане з голосом.

## Проблеми

| Симптом | Рішення |
|---|---|
| «Python 3.10 - 3.13 was not found» | Встанови Python 3.12 з python.org (3.14 поки не підтримується) |
| Китайська пише «потребує Python 3.10–3.12» | Встанови Python 3.12, видали папку `.venv` і запусти програму знову |
| Помилка під час першого встановлення або завантаження моделі | Перевір інтернет і спробуй ще раз (є кнопка «Спробувати ще раз») |
| Телефон не відкриває сторінку | Телефон і комп'ютер в одній Wi-Fi (не «гостьова» мережа); дозволь Python у брандмауері; перезапусти програму |
| macOS: «немає прав» або файл не запускається | Відкрий Terminal, перетягни туди папку й виконай `bash start.command` |
| Браузер не відкрився | Відкрий вручну `http://127.0.0.1:8765` |
| Хочу без доступу з мережі | Запусти `python app.py --local-only` |
| Хочу почати з нуля | Видали папку `.venv` і запусти знову |

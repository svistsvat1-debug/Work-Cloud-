# Voice Studio

Програма для озвучки: вставляєш англійський текст і отримуєш природний чоловічий голос.
Працює на твоєму комп'ютері: без акаунтів, підписок, API-ключів і лімітів на кількість хвилин.

- **Рушій:** Kokoro-82M (ліцензія Apache 2.0, комерційне використання дозволене, роялті немає).
- **Голоси:** 12 чоловічих (8 американських, 4 британських) + мікс двох голосів у свій унікальний.
- **На виході:** WAV (для монтажу), MP3 і субтитри `.srt` для YouTube.
- **Швидкість:** на звичайному ноутбуці приблизно 3 хвилини озвучки за 1 хвилину роботи. Відеокарта не потрібна.

## Запуск

Один раз потрібен **Python 3.12** → https://www.python.org/downloads/
(на Windows під час встановлення постав галочку **"Add python.exe to PATH"**).

| Система | Що зробити |
|---|---|
| Windows | двічі клікнути `start.bat` |
| macOS | двічі клікнути `start.command` (якщо macOS блокує: правий клік → «Відкрити») |
| Linux | `bash start.command` |

Перший запуск триває кілька хвилин: програма сама ставить компоненти й завантажує модель голосу (~350 MB).
Далі вона стартує за кілька секунд і працює без інтернету. Браузер відкриється сам на `http://127.0.0.1:8765`.
Щоб вимкнути програму, закрий чорне вікно консолі.

## Як користуватись

1. Встав текст сценарію. Порожній рядок між абзацами дає довшу паузу.
2. Обери голос і натисни ▶, щоб прослухати. ★ позначає найкращі голоси за оцінкою авторів моделі.
3. За бажання увімкни **«Свій унікальний голос»**: мікс двох голосів у вибраній пропорції.
   Запам'ятай комбінацію (наприклад, Michael 60% + Fenrir 40%) і використовуй її в усіх відео. Так у каналу буде впізнаваний голос, який не збігається з жодним стандартним.
4. **Озвучити** (або Ctrl+Enter). Готові файли лежать у папці `output/` і в списку «Останні озвучки».

Налаштування й чернетка тексту запам'ятовуються між запусками.

## Щоб звучало максимально по-людськи

- **Пунктуація керує інтонацією.** Кома дає коротку паузу, крапка дає паузу й спад інтонації, `?` і `!` теж звучать.
- **Короткі речення** звучать природніше за довгі.
- **Швидкість 0.95–1.05** найприродніша для оповіді. 1.1+ підходить для динамічних Shorts.
- **Словник вимови** (у бічній панелі): якщо слово читається неправильно, додай рядок `слово = як читати`,
  наприклад `SaaS = sass`, `Nguyen = win`. Словник зберігається у `pronunciations.json`.
- Програма сама виправляє типові проблеми: `$1,500` → "one thousand five hundred dollars", `in 2026` → "twenty twenty-six",
  `vs.` → "versus", `e.g.` → "for example", `#1` → "number one", `10x` → "10 times".
  Також прибирає markdown-розмітку (`**`, `#`, маркери списків), якщо текст скопійовано з ChatGPT.
- Відома слабкість: омографи на кшталт *read* (минулий час) іноді читаються як "reed".
  Тоді заміни слово у тексті або допиши його у словник вимови.

## Авторські права і YouTube

**Голос:**
- Модель Kokoro-82M поширюється під Apache 2.0. Ця ліцензія дозволяє комерційне використання без роялті й без обов'язкового згадування у відео.
- Голоси Kokoro не є клонами відомих людей, тож ризику «вкраденого голосу» немає.
  **Не клонуй** голоси реальних людей (блогерів, акторів) без їхньої згоди: це вже юридичний ризик.

**Монетизація YouTube:**
- AI-озвучка сама по собі не заборонена.
- Монетизацію знімають за **«inauthentic content»**: масові шаблонні відео з мінімальними відмінностями.
  Головне — власний сценарій, своя подача і цінність у кожному відео, а не тільки голос.
- Позначка «Altered or synthetic content» у YouTube Studio потрібна для реалістичного контенту, що може ввести в оману
  (наприклад, голос або обличчя реальної людини). Якщо сумніваєшся, постав позначку.
- Музика, футаж і картинки у відео — окреме питання ліцензій, не пов'язане з голосом.

## Проблеми

| Симптом | Рішення |
|---|---|
| «Python 3.10 - 3.13 was not found» | Встанови Python 3.12 з python.org (версія 3.14 поки не підтримується) |
| Помилка під час першого встановлення | Перевір інтернет і запусти ще раз |
| macOS: «немає прав» або файл не запускається | Відкрий Terminal, перетягни туди папку й виконай `bash start.command` |
| Браузер не відкрився | Відкрий вручну `http://127.0.0.1:8765` |
| Хочу почати з нуля | Видали папку `.venv` і запусти знову |

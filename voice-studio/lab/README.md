# Voice lab: як обирали голоси для 4 мов

Лабораторія працює в GitHub Actions (`.github/workflows/voice-lab.yml`), бо з тестового середовища DeepInfra недоступний.
Кожен пуш у `voice-studio/lab/` робить те, що написано в `run.sh`. Аудіо з попереднього запуску (`reuse_run.txt`)
завантажується знову, тож за ту саму озвучку двічі не платимо. На всі тести 14.10.2026 пішло приблизно $1,9 з балансу DeepInfra.

| Файл | Що робить |
|---|---|
| `probe.py` | список моделей озвучки DeepInfra: ціни, голоси, параметри |
| `synth.py` | озвучує тексти з `texts.json` усіма кандидатами з `candidates*.json` |
| `evaluate.py` | оцінює кожен файл: Whisper large-v3-turbo (помилки слів, яку мову чує), UTMOS (природність 1–5), висота голосу й класифікатор статі, темп, схожість голосу між текстами (ECAPA) |
| `asr_probe.py`, `fetch_docs.py` | розпізнавання мовлення на DeepInfra; ліцензії та документація Inworld |
| `live_test.py` | перевірка живого сайту: вхід, «Перевірити з'єднання», озвучка кожною мовою через справжню сторінку, оцінка MP3 |

Зміни лише в цьому README лабораторію не запускають.

## Що перевіряли

Тексти написані як живе мовлення YouTube-оповідача кожною мовою (не переклад):
- короткий монолог;
- довга історія;
- емоційні питання;
- «важкий» текст з датами, часом, цінами, відсотками, одиницями, скороченнями.

Кандидати:
- **моделі DeepInfra з чоловічими голосами** — Inworld TTS 1.5 max / mini / realtime-2, Qwen3-TTS (пресети й VoiceDesign), Chatterbox Multilingual, Audio8, MiMo, Zonos;
- **для англійської додатково** — Kokoro.

## Результати

Позначки в таблиці:
- **WER** — частка слів, які Whisper почув інакше;
- **MOS** — оцінка природності;
- **схожість** — наскільки це той самий голос на різних текстах;
- **чол.** — імовірність, що голос чоловічий.

| Мова | Обрано | Чому | Відсіяно |
|---|---|---|---|
| Англійська | Kokoro (Michael та ін., як і раніше) | WER 0 на довгому тексті, MOS 4,3–4,4 на рівні Inworld, найстабільніший голос (схожість 0,93–0,99), у 50 разів дешевший | — |
| Німецька | Inworld **Josef** | носій німецької, WER 0–0,04, чол. 0,999, схожість 0,88–0,94 | Lennart, Erik (голландський акцент); Qwen3 (голоси англомовні); Chatterbox та Audio8 (вигадували слова на довгому тексті; Audio8 ще й жіночий голос); MiMo (не говорить німецькою) |
| Іспанська | Inworld **Rafael** (основний), **Diego** | WER 0 на всіх текстах, схожість 0,89–0,96 | Kokoro em_alex / em_santa (MOS 2,5–3,0, звучить роботизовано); Qwen3 (голос «пливе» між текстами, 0,64) |
| Французька | Inworld **Lucian** (основний), **Alain** (швидший) | найкращий MOS серед французьких (до 4,0) | Chatterbox (помилки й вигадані слова); Qwen3 (надто швидко, 236–243 слів/хв) |

**Inworld mini** вдвічі дешевший, але частіше повторював фрази й гірше тримав голос (0,62–0,81), тому його не беремо.
**Realtime TTS-2** на довгому французькому тексті пропустив півречення.

### Важливі знахідки

1. **Довгі запити.** Inworld на запитах від приблизно 450 символів іноді повторює кінець або пропускає фразу. На запитах до 280 символів (36 проб, по 2 рази кожна) таких збоїв не було. Тому сайт ріже текст для Inworld на шматки до 280 символів.
2. **Підготовка тексту.**
   - Без підготовки голоси читали:
     - «2 l» як «zwei Lager» / «deux ailes»;
     - «Mo-Fr» як «Mo frei»;
     - «lun-vie» як «lumbie»;
     - «p. ej.» як «PEG»;
     - «11/10/2026» як «2226».
   - Після правил з `tests/natural_cases_cloud.json` (139 прикладів DE/ES/FR) усе прочитано правильно.
3. **Температура.** Нижча температура (0,8) помилок не зменшила, лишили стандартну.
4. **Маршрут.** OpenAI-подібний маршрут `/v1/audio/speech` віддає готовий WAV і враховує швидкість. Рідний маршрут параметр `speaking_rate` ігнорував.
5. **Перевірка розпізнаванням.** Whisper large-v3-turbo на DeepInfra коштує $0,0002 за хвилину і відповідає за 1–2 с. Сервер перевіряє ним кожен шматок Inworld і переозвучує, якщо слова не збігаються (до 3 спроб).

### Перевірка живого сайту (після розгортання)

`live_test.py` проходить сайт як людина: вхід, перевірка з'єднання, озвучка кожною мовою, скачування MP3.

| Текст | Результат |
|---|---|
| «Важкий» текст, 4 мови | Whisper почув саме те, що треба: дати, час, ціни, відсотки, скорочення |
| Довга історія DE і FR, 3 шматки кожна | усі шматки з першої спроби; голос чоловічий (0,99+) |

Швидкість: 6–9 с на 700 символів разом з перевіркою.
Josef говорить спокійно (≈ 120 слів/хв); прискорити можна повзунком «Швидкість».

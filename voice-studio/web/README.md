# Voice Studio · веб-версія

Та сама озвучка, але працює в браузері телефону чи комп'ютера, без сервера і без встановлення.
Модель голосу завантажується на пристрій один раз і далі працює навіть без інтернету.

**Зараз опубліковано як артефакт Claude:** https://claude.ai/artifact/CNnbKyYCuGUURcC4C61E33 (приватний, бачиш лише ти).

> Для довгих відео з телефону краще хмарна версія [`../cloud/`](../cloud/README.md): тут телефон рахує все сам,
> і 1,5 години озвучки займе кілька годин, а хмарна рахує на відеокартах сервера, тож у рази швидша.

## Що вміє

- 3 мови: англійська (12 голосів), німецька (Thorsten), іспанська (Alex).
- Мікс двох англійських голосів, швидкість, паузи, словник вимови.
- Час, дати, діапазони й одиниці читаються природно (`7.00 AM` → seven AM, `am 11.10.2026` → am elften Oktober); список у [`../README.md`](../README.md).
- Збереження: в артефакті це `.zip` з WAV, субтитрами SRT і текстом (артефакт не дозволяє зберігати .wav напряму).
  На звичайному сайті будуть окремі кнопки WAV і SRT.
- Історія останніх 8 озвучок на цьому пристрої.

## Швидкість

Озвучка рахується процесором телефону в одному потоці WebAssembly, тож вона повільніша, ніж
програма на комп'ютері: у тестах приблизно 3 секунди роботи на 1 секунду голосу (англійська, іспанська).
Німецька помітно швидша. Хвилинний сценарій займе кілька хвилин; екран має бути увімкнений.

На власному сайті можна пришвидшити в 2–4 рази: увімкнути багатопотоковість (заголовки
`Cross-Origin-Opener-Policy: same-origin` і `Cross-Origin-Embedder-Policy: require-corp`), рушій підхопить їх сам.

## Як влаштовано

```
index.html          інтерфейс
engine/worker.mjs   рушій у Web Worker: текст → речення → фонеми (espeak-ng) → ONNX-модель → WAV + SRT
build.py            збирає dist/: бібліотеки, голоси, моделі частинами по 14 MiB
```

Збирання: `pip install numpy onnx onnxruntime kokoro-onnx`, потім `python web/build.py`.
Готова папка `web/dist/` (~122 MB, у git не потрапляє) публікується як артефакт або як статичний сайт.

Двійкові файли мають розширення `.wasm` лише тому, що артефакти Claude віддають тільки веб-типи файлів.

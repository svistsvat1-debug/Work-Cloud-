# Voice Studio · хмарна версія (Cloudflare + DeepInfra)

Сайт для телефону: вставляєш англійський текст будь-якої довжини, отримуєш MP3 (або WAV) і субтитри.
Озвучку робить Kokoro-82M на відеокартах DeepInfra, тож телефон нічого не рахує.

- **Голос:** Kokoro-82M (Apache 2.0), 12 чоловічих голосів (US/UK). Монетизація дозволена.
- **Ціна:** Cloudflare безкоштовно. DeepInfra бере за символи: базова ціна на сторінці моделі $0,62 за 1 млн символів.
  Сайт просить пріоритетну чергу (priority, ×1,5 ≈ $0,93 за 1 млн), щоб довгі тексти не стояли в черзі:
  10 хв відео ≈ 9 000 символів ≈ $0,01; 1,5 год ≈ 80 000 символів ≈ $0,08. Сторінка сама показує оцінку під текстом.
  Ціни DeepInfra можуть змінитись, тож звір їх на кроці 1.
- **Безпека:** API-ключ лежить лише в Cloudflare і до браузера не потрапляє; сайт закритий паролем.
- **Довжина тексту:** обмеження немає. Сторінка ділить текст на шматки й озвучує по 4 одночасно.
  «Скачати аудіо» дає MP3 128 kbps (≈ 1 MB на хвилину, 1,5 год ≈ 85 MB); WAV без стиснення (≈ 2,9 MB на хвилину)
  вмикається в Налаштуваннях → Формат файлу. MP3 робиться прямо на пристрої після озвучки (на кнопці видно відсотки).

```
cloud/
  wrangler.toml       налаштування Worker (назва voice-studio-app, сторінка з public/)
  package.json        закріплена версія wrangler для збірки в Cloudflare
  src/worker.js       сервер: вхід за паролем, передає текст у DeepInfra, повертає аудіо
  public/index.html   сторінка: ділить текст, озвучує по 4 шматки одночасно, склеює WAV + SRT
  public/mp3-worker.js перетворює готовий WAV у MP3 у фоновому потоці
  public/vendor/      lamejs 1.2.1 (кодек LAME, LGPL-3.0) для MP3
```

## Покрокова інструкція (все можна зробити з телефону)

Та сама інструкція як чек-лист для телефону (галочки, кнопки «Копіювати», генератор пароля):
https://claude.ai/artifact/KJReCEYhpofbafG46xzere (приватний, бачиш лише ти).

### Крок 1. Акаунт DeepInfra і баланс
1. Відкрий **deepinfra.com** → Sign up (найпростіше через Google або GitHub).
2. У кабінеті знайди оплату (Billing / Payment) → додай картку → поповни на **$5**.
3. Відкрий сторінку моделі **hexgrad/Kokoro-82M** на DeepInfra і подивись ціну за символи.

✅ **Перевірка:** у кабінеті видно баланс $5. На сторінці моделі ціна близька до $0,62 за 1M символів.
Якщо там значно більше, озвучка все одно працюватиме, просто дорожче: напиши Claude, і я виправлю оцінку на сторінці.

### Крок 2. API-ключ DeepInfra
1. У кабінеті DeepInfra відкрий **API Keys** → створи новий ключ (назва, наприклад, `voice-studio`).
2. Скопіюй ключ у нотатки. Нікому його не показуй.

✅ **Перевірка:** ключ скопійовано (довгий рядок літер і цифр). Чи він робочий, сайт покаже на кроці 6.

### Крок 3. Токен Cloudflare
Сайт розгортає GitHub (файл `.github/workflows/voice-studio.yml`), а не майстер у панелі Cloudflare:
майстер видавав «This Worker does not exist on your account» навіть для Hello World.
1. **dash.cloudflare.com** → іконка профілю → **My Profile** → **API Tokens** → **Create Token**.
2. Шаблон **Edit Cloudflare Workers** → **Use template**.
3. **Account Resources:** свій акаунт; **Zone Resources:** All zones → **Continue to summary** → **Create Token**.
4. Скопіюй токен у нотатки (Cloudflare показує його один раз).

✅ **Перевірка:** токен у нотатках.

### Крок 4. Три секрети в GitHub
https://github.com/svistsvat1-debug/Work-Cloud-/settings/secrets/actions/new, три рази **Add secret**:

| Name | Secret |
|---|---|
| `CLOUDFLARE_API_TOKEN` | токен з кроку 3 |
| `DEEPINFRA_API_KEY` | ключ з кроку 2 |
| `SITE_PASSWORD` | пароль для сайту, від 12 символів |

Далі кожен пуш у гілку `voice-studio` зі змінами в `voice-studio/cloud/` сам розгортає сайт і прописує секрети
(пробіли й переноси рядка в них обрізаються). Перезапуск вручну: GitHub → **Actions** → **Deploy Voice Studio** → **Re-run**.

✅ **Перевірка:** в Actions зелений запуск, останній крок показує `{"password":true,"apiKey":true,...}`.
Сайт: **https://voice-studio-app.svistsvat1.workers.dev**. Назва `voice-studio-app`, бо Cloudflare не дає створити
Worker з назвою `voice-studio` (помилка 10007, ймовірно, після першої невдалої спроби через «Import a repository»).

### Крок 5. Вхід
Введи `SITE_PASSWORD` → **Увійти**.

✅ **Перевірка:** відкрилась студія: велика картка для тексту, внизу чипи з голосом і біла кнопка ▶, у куті шестерня (налаштування).
Вхід пам'ятається на пристрої 180 днів. Якщо під полем входу видно «Порада: пароль коротший за 12 символів»,
заміни секрет `SITE_PASSWORD` у GitHub на довший і перезапусти розгортання (крок 4): з паролем можна витратити твій баланс DeepInfra.

### Крок 6. Перевірка з'єднання з DeepInfra
Шестерня в куті картки → **«Перевірити з'єднання»** (внизу налаштувань).

✅ **Перевірка:** зелений текст на кшталт
«✓ Працює: DeepInfra повернув голос за 1.2 с (маршрут speech, priority). усі 12 голосів доступні (у моделі …).»
- `speech` означає основний маршрут. `openai` чи `native` теж нормально: це запасні маршрути.
- `priority` означає пріоритетну чергу. `standard` означає, що DeepInfra не дає пріоритет для цієї моделі: озвучка працює, просто без доплати ×1,5.
- Жовтий текст з «⚠» означає, що озвучка працює, але є зауваження (наприклад, якогось голосу немає). Скинь скріншот Claude.
- Червоний текст означає, що озвучка не працює. Дивись таблицю «Якщо щось не так» нижче.

### Крок 7. Перша озвучка
1. Обери голос на чипах (США / Британія, ім'я диктора). Зразок голосу: шестерня → **«Прослухати голос»**.
2. Встав 2–3 речення англійською → біла кнопка **▶** (озвучити).
3. Натисни **Скачати аудіо** (MP3) і **Скачати субтитри**.

✅ **Перевірка:** файл відтворюється в плеєрі на сторінці і з'явився в «Файли → Завантаження» (iPhone)
або в «Завантаженнях» (Android). Кнопка **«Поділитися»** (якщо є) відправляє файл одразу в CapCut чи Telegram.

### Крок 8. Довге відео
1. Встав сценарій на 10+ хвилин. Під текстом видно кількість слів, тривалість і ціну.
2. Біла кнопка **▶**. Поки йде прогрес, сторінку краще не закривати (екран телефону сайт тримає увімкненим сам).
3. Якщо інтернет зник або ти згорнув браузер, натисни **«Продовжити озвучку»**: озвучиться лише те, чого бракує, без повторної оплати готових шматків.

✅ **Перевірка:** у рядку прогресу видно «Озвучую: X з Y · залишилось ≈ …»; після готовності довжина аудіо відповідає очікуваній.
Запиши, скільки хвилин зайняла озвучка: це реальна швидкість DeepInfra (з тестового середовища її не виміряти).
У кабінеті DeepInfra витрата має бути на рівні центів.
Остання озвучка зберігається на пристрої: якщо сторінка перезавантажилась, вона з'явиться знову з кнопками завантаження.

**Мобільний інтернет:** галочка **«Економити мобільний інтернет»** просить сервер слати звук у MP3 (утричі менше трафіку).
Формат готового файлу не змінюється (MP3 чи WAV, як у налаштуваннях), але якість трохи нижча. Через Wi-Fi галочку краще не ставити.

### Крок 9. Іконка на головному екрані
iPhone: Safari → «Поділитися» → «На екран Додому». Android: Chrome → ⋮ → «Додати на головний екран».

✅ **Перевірка:** іконка відкриває сайт у Safari / Chrome одразу в студії, без повторного входу.
Сайт навмисно відкривається в браузері, а не окремим застосунком: так на iPhone спільний вхід і надійне збереження файлів.

## Якщо щось не так

| Що видно | Що робити |
|---|---|
| Розгортання в GitHub Actions червоне | Перевір три секрети (крок 4). Якщо не допомогло, скинь Claude посилання на запуск в Actions |
| «Сайт ще не налаштовано» після додавання секретів | Перевір назви секретів (великі літери, без пробілів), зачекай хвилину й натисни «Перевірити ще раз» |
| «DeepInfra не приймає API-ключ» | Скопіюй ключ ще раз (без пробілів) і заміни секрет `DEEPINFRA_API_KEY` |
| «На рахунку DeepInfra закінчились кошти» | Поповни баланс на deepinfra.com, потім «Продовжити озвучку» |
| «Сервіс озвучки відповів помилкою 4xx» | Скинь скріншот Claude: можливо, DeepInfra змінив формат запиту |
| «Забагато запитів», «тимчасово недоступний», «Немає зв'язку з сервісом озвучки» | Сторінка сама повторює до 5 разів. Якщо не допомогло, зачекай хвилину й натисни «Продовжити озвучку» |
| «Немає з'єднання з сервером» | Перевір інтернет на телефоні й натисни «Продовжити озвучку» |
| «Сесія закінчилась» | Увійди ще раз і натисни «Продовжити озвучку»: готові шматки не загубляться |
| «Неправильний пароль» | Пароль = значення `SITE_PASSWORD`; після 10 помилок вхід блокується на 15 хв |
| Хочу змінити пароль | Зміни секрет `SITE_PASSWORD` у GitHub і перезапусти розгортання: усі пристрої вийдуть із системи |
| Хочу вимкнути пріоритетну чергу (дешевше в 1,5 раза, але можливі черги) | Settings → Variables and Secrets → Add: Type **Text**, Name `DEEPINFRA_TIER`, Value `off` → Deploy |

## Технічно

- Сторінка ділить текст на речення і перед озвучкою переписує те, що голос читає неприродно: час (`7.00 AM` → seven AM,
  `19:00` → seven PM), дати (`Oct. 11, 2026` → October eleventh, twenty twenty-six), діапазони (`5-10` → five to ten),
  дроби, одиниці (`10 min`, `2L`, `5 km`), гроші (`$1,500`), роки, `vs.`, `e.g.` і слова зі словника вимови. Повний список у `../README.md`.
  Потім збирає речення абзацу в запити до 800 символів, надсилає по 4 запити одночасно, повторює тимчасові збої,
  обрізає тишу й ставить точні паузи. Час субтитрів ділиться між реченнями пропорційно довжині.
- Сервер звертається до документованого маршруту DeepInfra `/v1/audio/speech` з `service_tier: "priority"`.
  Якщо модель не приймає priority, повторює той самий запит без нього й запам'ятовує це. Якщо маршрут недоступний,
  пробує `/v1/openai/audio/speech`, потім рідний `/v1/inference/hexgrad/Kokoro-82M` (JSON з base64). Сторінка розпізнає обидва формати.
- Перевірка з'єднання, крім тестової фрази, читає публічну схему моделі (`/models/hexgrad/Kokoro-82M`):
  чи є всі 12 голосів, формати, максимальна довжина запиту.
- Перевірено локально у workerd (той самий рушій, що в Cloudflare) з імітацією DeepInfra на iPhone-екрані:
  справжній голос Kokoro, усі три маршрути, відмова від priority, неправильний ключ, збої 429, обрив мережі,
  закінчення сесії посеред озвучки, скасування й продовження, MP3-режим, текст на 1,5 години з завантаженням WAV і SRT.
  Справжній DeepInfra з тестового середовища недоступний, тож перша реальна перевірка — крок 6.

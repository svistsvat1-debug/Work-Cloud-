# Voice Studio · хмарна версія (Cloudflare + DeepInfra)

Сайт для телефону: вставляєш англійський текст будь-якої довжини, отримуєш WAV і субтитри.
Озвучку робить Kokoro-82M на відеокартах DeepInfra, тож телефон нічого не рахує.

- **Голос:** Kokoro-82M (Apache 2.0), 12 чоловічих голосів (US/UK). Монетизація дозволена.
- **Ціна:** Cloudflare безкоштовно. DeepInfra приблизно $0,62 за 1 млн символів (перевір актуальну ціну на сторінці моделі):
  10 хв відео ≈ 9 000 символів ≈ $0,006; 1,5 год ≈ 80 000 символів ≈ $0,05.
- **Безпека:** API-ключ лежить лише в Cloudflare і до браузера не потрапляє; сайт закритий паролем.

```
cloud/
  wrangler.toml     налаштування Worker (назва voice-studio, сторінка з public/)
  src/worker.js     сервер: вхід за паролем, передає речення в DeepInfra, повертає аудіо
  public/index.html сторінка: ділить текст на речення, озвучує по 4 одночасно, склеює WAV + SRT
```

## Покрокова інструкція (все можна зробити з телефону)

### Крок 1. Акаунт DeepInfra і баланс
1. Відкрий **deepinfra.com** → Sign up (найпростіше через Google або GitHub).
2. У кабінеті знайди оплату (Billing / Payment) → додай картку → поповни на **$5**.
3. Відкрий сторінку моделі **hexgrad/Kokoro-82M** на DeepInfra і подивись ціну за символи.

✅ **Перевірка:** у кабінеті видно баланс $5.

### Крок 2. API-ключ DeepInfra
1. У кабінеті DeepInfra відкрий **API Keys** → створи новий ключ (назва, наприклад, `voice-studio`).
2. Скопіюй ключ у нотатки. Нікому його не показуй.

✅ **Перевірка:** ключ скопійовано (довгий рядок літер і цифр). Чи він робочий, сайт покаже на кроці 6.

### Крок 3. Створити Worker у Cloudflare
1. **dash.cloudflare.com** → **Workers & Pages** → **Create** → **Import a repository**.
2. Обери GitHub-акаунт і репозиторій **Work-Cloud-** (той самий, що й для журналу).
3. Налаштування проєкту:
   - **Project name:** `voice-studio`
   - **Build command:** залиш порожнім
   - **Deploy command:** `npx wrangler deploy` (стоїть за замовчуванням)
   - **Root directory** (у розділі Advanced / Path): `voice-studio/cloud`
4. Натисни **Deploy**. Перша збірка, найімовірніше, **впаде**: Cloudflare бере гілку `main`, а код лежить у гілці `voice-studio`.
   Це нормально, так само було з журналом.
5. Worker → **Settings → Build → Branch control** → **Production branch** = `voice-studio` → **Save**.
6. **Deployments** → **Retry deployment** (або будь-який новий deploy).

✅ **Перевірка:** у Deployments статус **Success**, є адреса виду `https://voice-studio.<твій-піддомен>.workers.dev`.
Відкрий її: має з'явитися сторінка **«Сайт ще не налаштовано»** зі списком із двох секретів. Отже, Worker працює.

### Крок 4. Секрети (ключ і пароль)
Worker `voice-studio` → **Settings** → **Variables and Secrets** → **Add**:
1. Type **Secret**, Name `DEEPINFRA_API_KEY`, Value: ключ з кроку 2 → **Save / Deploy**.
2. Type **Secret**, Name `SITE_PASSWORD`, Value: придумай пароль від 12 символів → **Save / Deploy**.

✅ **Перевірка:** онови сайт. Список «бракує» зник, з'явилось поле **«Вхід»**.

### Крок 5. Вхід
Введи `SITE_PASSWORD` → **Увійти**.

✅ **Перевірка:** відкрилась студія: поле для тексту, голос, кнопка «Озвучити».
Вхід пам'ятається на пристрої 180 днів.

### Крок 6. Перевірка з'єднання з DeepInfra
Внизу налаштувань розгорни **«Перевірка з'єднання»** → **Перевірити**.

✅ **Перевірка:** зелений текст «✓ Працює: DeepInfra повернув голос за … с».
Якщо червоний, дивись таблицю «Якщо щось не так» нижче.

### Крок 7. Перша озвучка
1. Обери голос → **▶** (прослухати зразок).
2. Встав 2–3 речення англійською → **Озвучити**.
3. Натисни **⬇ WAV** і **⬇ Субтитри**.

✅ **Перевірка:** файл відтворюється в плеєрі на сторінці і з'явився в «Файли → Завантаження» (iPhone)
або в «Завантаженнях» (Android). Кнопка **«Поділитися файлом…»** (якщо є) відправляє WAV одразу в CapCut чи Telegram.

### Крок 8. Довге відео
Встав сценарій на 10+ хвилин → **Озвучити**. Сторінку не закривай, поки йде прогрес.

✅ **Перевірка:** у рядку прогресу видно «залишилось ≈ …»; після готовності довжина аудіо відповідає очікуваній.
У кабінеті DeepInfra витрата має бути копійчаною (центи).

### Крок 9. Іконка на головному екрані
iPhone: Safari → «Поділитися» → «На екран Додому». Android: Chrome → ⋮ → «Додати на головний екран».

## Якщо щось не так

| Що видно | Що робити |
|---|---|
| Збірка в Cloudflare впала | Перевір Root directory `voice-studio/cloud` і Production branch `voice-studio` (крок 3, пункти 3–6) |
| «Сайт ще не налаштовано» після додавання секретів | Перевір назви секретів (великі літери, без пробілів), зачекай хвилину й онови |
| «DeepInfra не приймає API-ключ» | Скопіюй ключ ще раз (без пробілів) і заміни секрет `DEEPINFRA_API_KEY` |
| «На рахунку DeepInfra закінчились кошти» | Поповни баланс на deepinfra.com |
| «Сервіс озвучки відповів помилкою 4xx» | Скинь скріншот Claude: можливо, DeepInfra змінив формат запиту |
| «Забагато запитів» / «тимчасово недоступний» | Сторінка повторює сама; якщо не допомогло, спробуй за кілька хвилин |
| «Неправильний пароль» | Пароль = значення `SITE_PASSWORD`; після 10 помилок вхід блокується на 15 хв |
| Хочу змінити пароль | Зміни секрет `SITE_PASSWORD`: усі пристрої вийдуть із системи |

## Технічно

- Сторінка ділить текст на речення (з нормалізацією `$1,500`, років, `vs.`, `e.g.` і словником вимови),
  надсилає по 4 запити одночасно, повторює тимчасові збої, обрізає тишу й ставить точні паузи.
- Сервер пробує OpenAI-сумісний маршрут DeepInfra (`/v1/openai/audio/speech`), а якщо його немає,
  то рідний (`/v1/inference/hexgrad/Kokoro-82M`). Відповідь у будь-якому з двох форматів сторінка розпізнає сама.
- Перевірено локально з імітацією DeepInfra (обидва формати відповіді, неправильний ключ, збої 429):
  текст на 4 хв зібрався в один WAV із субтитрами. Справжній DeepInfra з тестового середовища недоступний,
  тож перша реальна перевірка — крок 6.

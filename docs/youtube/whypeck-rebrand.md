## 2. Формула стилю

`WhyPeck` = **Why** (формат каналу — питання «чому?») + **одне коротке «звукове» слово-дія** (peck — клюнути).
Нова назва зберігає формулу: Why + 1 склад, звук/дія, CamelCase, 6–8 літер, легко сказати і написати.

## 6. Чекліст перейменування

1. YouTube Studio → Customization → Basic info: **Name** = WhyZap, **Handle** = @whyzap (Studio одразу покаже, чи вільний), **Description** = текст із п.4.
2. Customization → Branding → Banner image → `banner-whyzap-2560x1440.png`. Аватарку не міняти.
3. YouTube дозволяє міняти назву/handle **2 рази за 14 днів**; старий @whypeck ще 14 днів веде на канал, потім звільняється → обрати назву один раз, без «тестових» змін.
4. Оновити згадки старої назви: тег `whypeck` у відео «This Bird's Tongue Goes Around Its ENTIRE Skull» → `whyzap`; посилання на @whypeck у соцмережах/описах, якщо є.

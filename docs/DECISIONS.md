## Відкриті рішення — потрібні від власника

1. **Ринок + мова сайту:** Україна / діаспора-ЄС / міжнародний (EN)? → впливає на копірайт і ціни.
2. **Назва компанії** (кандидати-напрямки, обрати/дати свій):
   - WorkCloud (від поточного домену)
   - [напрям «система»: напр. SystemFlow, LeadSystem]
   - [напрям «результат»: напр. ClientEngine]
   - свій варіант
   > Назву НЕ фіксую сам — це рішення власника.
3. **Вертикаль №1:** сервісні бізнеси / консультанти-експерти / агентства?
4. **Ціни пакетів:** підтвердити підхід (фікс за проєкт + місячний care plan) і суми/валюту.
5. **Інструменти:** CRM (HubSpot free?), booking (Cal.com?), автоматизація (Make/n8n?).
6. **TikTok англійською vs сайт українською:** TikTok веде англомовну аудиторію, а чернетка сайту (`WEBSITE.md`) — українською. Якщо ринок не визначено, трафік із біо не конвертується → потрібне рішення по ринку (п.1) і, ймовірно, EN-версія сайту.
7. **Сайт для CTA-відео (терміново, перше CTA-відео — Day 3):** живий EN-сайт з формою/booking, домен, TikTok handle, оффер для CTA (рекомендація — безкоштовна перевірка сайту).

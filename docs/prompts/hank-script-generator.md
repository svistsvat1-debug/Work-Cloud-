# Hank Stories — генератор сценаріїв (одне унікальне відео на команду)

Версія: 2026-10-24 · сам промпт: `hank-script-generator-prompt.txt` (копіювати цілком).
Без плану, без номерів епізодів і дат: лише правила каналу, і щоразу нова історія.

## Як користуватися

1. Новий чат → вставити весь текст із `hank-script-generator-prompt.txt` → відповідь "Ready. Send LONG."
2. `LONG` (або `ДОВГЕ`) → одне довге відео: сценарій блоками коду до 4 500 знаків + назви, опис, теги, промпти.
3. `SHORT` (або `ШОРТС`) → шортс для щойно написаної довгої історії, з тими самими фактами.
4. `FIX ...` (або `ВИПРАВ ...`) → переробити останнє відео.
5. Кожен `LOG LINE` з відповідей дописувати в `USED LOG` промпта. Кожні 3–4 відео — новий чат з оновленим промптом.

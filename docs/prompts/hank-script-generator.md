# Hank Stories — генератор сценаріїв (тільки сценарій, один блок коду)

Версія: 2026-10-24 · сам промпт: `hank-script-generator-prompt.txt` (копіювати цілком).
Відповідь генератора = один блок коду з повним сценарієм. Без назв, описів, тегів, обкладинок і розбиття на частини.

## Як користуватися

1. Новий чат → вставити весь текст із `hank-script-generator-prompt.txt` → відповідь "Ready. Send LONG."
2. `LONG` (або `ДОВГЕ`) → один повний довгий сценарій (2 600–3 200 слів) одним блоком коду.
3. `SHORT` (або `ШОРТС`) → сценарій шортса (75–90 слів) до щойно написаної довгої історії, з тими самими фактами.
4. `FIX ...` (або `ВИПРАВ ...`) → переробити останній сценарій.
5. Щоб не було повторів між чатами: після кожної історії дописати в `USED LOG` один рядок своїми словами (про що історія + предмет + штат + рік). Кожні 3–4 історії — новий чат з оновленим промптом.

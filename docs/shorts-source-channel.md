# Shorts-проєкт: канал-джерело для переробки

Дата пошуку: 2026-11-16 (дані vidIQ)

## Вимоги
- Безликий канал (faceless), популярний
- Тільки довгі відео (0 Shorts)
- Велика бібліотека відео (вистачить на 3 shorts/день надовго)
- Одна тематика
- Джерело — лише один канал

## Рекомендація №1 — Top 5 Unknowns
- URL: https://www.youtube.com/@top5unknowns
- Тематика: загадки, паранормальне, true crime, моторошні історії
- Підписники: ~2.18M
- Відео: ~2316 довгих, Shorts: 0
- Нові відео: ~33/місяць
- Формат: списки «5 …» → з одного довгого відео виходить 3–5 shorts
- Запас: 3 shorts/день ≈ 1095/рік → матеріалу на багато років

# Shorts-проєкт: канал-джерело для переробки

Дата пошуку: 2026-11-16 (дані vidIQ)

## Мій канал
- WhyZap — https://www.youtube.com/@whyzap1
- Мова: англійська
- Формат: Shorts ~30 сек, мультяшна анімація, «чому…?», цікаві питання з несподіваними відповідями
- Теми: наука, тварини, космос, тіло людини, історія, інженерія
- Старт: 2026-10-28, ~49 shorts

## Вимоги до джерела
- Безликий канал (faceless), популярний
- Тільки довгі відео (0 Shorts)
- Велика бібліотека (вистачить на 3 shorts/день надовго)
- Одна тематика, що збігається з WhyZap (цікаві факти / наука / «чому»)
- Джерело — лише один канал

- Відео: ~2544 довгих, Shorts за рік: 0

## Правила переробки
- Брати факт/питання → переписати своїми словами → власна озвучка + власна мультяшна анімація

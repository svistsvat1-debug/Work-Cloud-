# YouTube-аналізатор: готові варіанти (жовтень 2026)

Задача: вставляю посилання або відкриваю відео на YouTube → бачу розширений аналіз: перегляди, орієнтовний заробіток, обкладинки, назви, опис, outlier-оцінку, конкурентів, топи. Безкоштовно або дешево.

## 0. Що взагалі можна дізнатись про чуже відео

| Дані | Чуже відео | Звідки |
|---|---|---|
| Перегляди, лайки, коментарі, дата, тривалість | ✅ точно | YouTube Data API / сторінка |
| Назва, опис, теги, обкладинка, категорія | ✅ точно | YouTube Data API |
| Підписники каналу | ✅ (округлені) | YouTube Data API |
| «Most replayed» (які моменти переглядають повторно) | ✅ | публічна теплова карта (yt-dlp) |
| Перегляди за годину, outlier (у скільки разів краще за середнє каналу) | ✅ розрахунок | знімки переглядів у часі + медіана каналу |
| Історія змін назви / обкладинки | ✅ тільки з моменту, як інструмент почав стежити | регулярні знімки |
| Заробіток | ⚠️ тільки оцінка-діапазон | перегляди × RPM ніші |
| **CTR, покази, утримання, джерела трафіку, підписки з відео, реальний дохід** | ❌ **неможливо** | бачить лише власник у YouTube Studio |

Висновок: жоден сервіс не показує справжній CTR чи утримання чужого відео. Якщо показує — це здогадка. Реальні CTR і утримання доступні лише по **твоїх** каналах (через Google-вхід).

| Інструмент | Що дає безкоштовно | Платно |

## 2. Свій сервер з GitHub (open source)

### ⭐ youtube-niche-finder — найближче до того, що треба
https://github.com/pandich93/youtube-niche-finder · MIT · 22★ · оновлювався 24.10.2026 · 317 комітів

- Розширення для Chrome: показує дані поверх сторінок YouTube.
- Веб-дашборд (27 розділів), HTTP API, CLI, MCP-сервер (100 інструментів) для Claude.
- Outlier-відео з малих каналів, перегляди за годину, діапазони RPM і доходу (позначені як оцінка).
- Відстеження змін назв і обкладинок (перегляди до/після), ріст каналів, пороги монетизації.
- Оцінка ніш 0–100, порівняння ніш, тренди, спільні риси outlier-ів (числа/питання в назвах, довжина, день, час).
- «Outlier → бриф»: хук, патерни назв, кандидати назв, референси обкладинок.
- Сповіщення в Telegram: новий outlier у конкурента, зміна назви/обкладинки.
- Сигнали ризику «inauthentic content» (шаблонні канали).
- Стек: Python/FastAPI, PostgreSQL + pgvector, Docker. Потрібен безкоштовний ключ YouTube Data API v3.
- Запуск: `git clone` → `.env` з `YOUTUBE_API_KEY` → `docker compose build && make up` → http://localhost:8080.
- Ризики: малий проєкт (22★), розробник фактично один; обмеження безкоштовної квоти YouTube API.

### Outlier-Lab — простіший, локальний
https://github.com/jobtanut/Outlier-Lab · MIT · Python без залежностей + SQLite

- Outlier-пошук по конкурентах, темах, форматах назв, посиланнях і плейлистах.
- Плюс **твій** канал через Google-вхід: CTR, утримання, середній перегляд, підписки, джерела трафіку, аудиторія.
- Запуск: `python3 server.py` → http://localhost:8765.
- Мінуси: пропускає відео молодші за 7 днів, без розширення для Chrome.

## 3. Рекомендація

1. **Сьогодні, 0 $:** поставити 1of10 і OutlierKit у Chrome — outlier-оцінки й перегляди в часі прямо на YouTube.
2. **Цього тижня, 0 $:** запустити youtube-niche-finder на своєму комп'ютері через Docker. Якщо зайде — перенести на найдешевший VPS ([MISSING] ціна залежить від провайдера), щоб збирав дані 24/7 і слав сповіщення в Telegram.
3. **Свою програму з нуля не писати.** Замість цього — форк niche-finder і додати те, чого бракує: AI-розбір обкладинки й назви (чому зачепило), готові висновки під HFY і Hank, експорт у наш пакувальний промпт.
4. Для своїх каналів — справжні CTR/утримання через Google-вхід (є і в niche-finder, і в Outlier-Lab).

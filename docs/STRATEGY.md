## 1. Positioning (рекомендація)

**Ми не веб-студія. Ми будуємо цифрову систему, яка перетворює відвідувачів на клієнтів.**

Головне формулювання (рекомендоване, на затвердження):
> «Ми будуємо для бізнесу цифрову систему: сайт → заявки → CRM → автоматизація → follow-up. Менше ручної роботи, більше клієнтів.»

Коротка версія (tagline-кандидати — обрати один):
1. «Цифрова система, яка приносить клієнтів.»
2. «Від відвідувача до клієнта — на автоматі.»
3. «Сайт, що працює як система продажів.»

Чого уникаємо: «ми робимо сайти», «ми інтегруємо AI». Продаємо **результат**, не технологію.

## 2. ICP — хто наш клієнт (рекомендація звузити старт)

На старті фокус на **одному зрозумілому сегменті** (легше меседжити й знаходити):

**Основний ICP:** локальні сервісні бізнеси, експерти, консультанти, агентства, що:
- запускаються або мають застарілий сайт, який не дає заявок;
- отримують ліди хаотично (Instagram, дзвінки, месенджери);
- відповідають клієнтам вручну, втрачають заявки;
- 0–10 людей у команді, власник у операційці.

**Тригери звернення:** «немає нормального сайту», «заявки губляться», «не встигаю відповідати», «запускаю бізнес».

> Рішення для затвердження: обрати 1 вертикаль для перших меседжів (напр. сервісні бізнеси АБО консультанти/експерти). Зараз: `[MISSING]`.

## 3. Offer — продуктизовані пакети

Три рівні + план підтримки. Кожен прив'язаний до бізнес-результату, не до «кількості сторінок».

### Пакет 1 — LAUNCH (швидкий старт)
Для тих, кому треба професійна присутність і перші заявки.
- Conversion-лендинг (1 сторінка, mobile-first, швидкий);
- Форма заявки + миттєве повідомлення власнику (email/Telegram);
- Базове відстеження заявок (проста табличка/CRM).
- **Результат:** сайт, який дає заявки, а не просто «є».

### Пакет 2 — GROWTH SYSTEM (система отримання клієнтів)
Для бізнесу, що хоче систему, а не просто сайт.
- Багатосторінковий сайт (Home / Послуги / Як працюємо / Контакти);
- CRM + автоматична передача лідів;
- Booking / запис;
- Follow-up автоматизація (нагадування, листи);
- Базова аналітика заявок.
- **Результат:** visitor → lead → CRM → follow-up → клієнт, без ручної рутини.

### Пакет 3 — AI SYSTEM (система + AI)
Growth System + AI там, де реально корисно.
- AI FAQ / support асистент на сайті;
- AI кваліфікація лідів;
- AI-генерація відповідей / документів;
- Workflow-автоматизації між системами.
- **Результат:** швидші відповіді клієнтам, менше ручної роботи, масштабованість.

### CARE PLAN (щомісячна підтримка — рекурентний дохід)
Хостинг-нагляд, правки, моніторинг заявок, покращення conversion, звіт.

> **Ціноутворення:** рекомендований підхід — value-based (фіксована ціна за проєкт + місячний care plan), не погодинно.
> Конкретні суми та валюта залежать від ринку → `[MISSING]` (див. DECISIONS.md, блок «Пакети послуг і ціни»).

## 4. Customer Journey

```
TRAFFIC → WEBSITE → LEAD → QUALIFICATION → CRM → AUTOMATION → FOLLOW-UP → CUSTOMER → RETENTION
```

| Етап | Що відбувається | Чим забезпечуємо |
|---|---|---|
| Traffic | людина дізнається про бізнес | соцмережі, реферали, реклама |
| Website | розуміє offer за 5 сек | чіткий hero + CTA |
| Lead | лишає заявку | форма / booking |
| Qualification | відсів нецільових | AI/форма з 2–3 питаннями |
| CRM | лід не губиться | авто-передача в CRM |
| Automation | без ручної рутини | нотифікації, листи |
| Follow-up | дотиск до угоди | автосерія нагадувань |
| Customer | угода | онбординг-процес |
| Retention | повтор/рефер | care plan, апсейл |

## 5. Можливості автоматизації (для клієнтів і для нас)

Автоматизувати лише те, що економить час / не втрачає ліди / прискорює відповідь / підвищує conversion:
- заявка → миттєва нотифікація + запис у CRM;
- авто follow-up, якщо немає відповіді 24/48 год;
- підтвердження та нагадування про зустріч;
- авто-відповіді на типові питання (AI FAQ);
- кваліфікація ліда до дзвінка;
- збір і структурування даних заявки.

Правило: якщо автоматизація складніша/дорожча за простий процес — пропонуємо простіше.

---

## 6. Де AI реально корисний

- **AI FAQ / Support** — відповіді на однотипні питання 24/7;
- **AI Lead Qualification** — оцінка і сортування заявок;
- **AI генерація** — чернетки відповідей, комерційних, документів;
- **AI Internal Assistant** — пошук по базі знань команди.

Не додаємо AI «бо модно» — лише з прямою користю.

2. **Назва компанії** (кандидати — в DECISIONS.md).

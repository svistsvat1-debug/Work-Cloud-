# Why Bees Die After Stinging You 🐝 — Крок 3: анімація (Remotion)

Метод: skill `cutout-cartoon-shorts`. Відступи від skill через середовище:
- **Картинки:** Google Flow (Nano Banana) від власника, без Higgsfield. Фон `#9BCFFD` вирізаю кодом (`key.py`).
- **Голос:** take1 від власника (ElevenLabs `eleven_v4`, голос Mark — Natural Conversations). Перезаписувати не було як: у сесії немає доступу до ElevenLabs.
- **Звуки:** синтезовані в коді (`sfx.py`). Ні бібліотеки звуків, ні Higgsfield тут немає.
- **Рендер:** на CPU (4 ядра), бо GPU в хмарному контейнері немає.

## Перезапуск

```bash
cd shorts && npm install
cd images/bees && python3 -I key.py raw/<file>.jpg cut/<file>.png   # для нової картинки
python3 -I prep.py && python3 -I sfx.py && cd ../..
node scripts/stills.mjs images/bees/qa/frames 0 2.2 4.7          # кадри для перевірки (REBUNDLE=1 після змін коду)
npx remotion render src/index.ts BeesSting out/bees-4K.mp4 --scale=2 --image-format=png --crf=16 --pixel-format=yuv420p
scripts/verify.sh out/bees-4K.mp4
```

## Перевірки (QA)

- **Вирізання:** усі 23 картинки на зеленому QA-аркуші (`shorts/images/bees/qa/sheet_cut.png`), точки прив'язки — `sheet_anchors.png`.
- **Контактний аркуш:** кадр на кожному біті — `shorts/images/bees/qa/contact_beats.png`, щільні кадри в складних місцях — `contact_dense.png`.
- **Pop-скан** превʼю 540×960: знайшов 3 непланові стрибки й усі виправлені:
  - 4,40 с — зміна точки прив'язки бджоли;
  - 5,65 с — наїзд камери стартував ривком;
  - 17,6 с — відлетіле жало поверталося в кадр.

  Решта прапорців задумані: заміни поз (2,10 · 2,45 · 5,96 · 21,15 · 21,85), удари (2,18 · 4,70 · 9,73 · 16,82) і склейки (6,93 · 17,70 · 23,18).
- **Звук (превʼю):** пік −6,6 dBFS, кліпінгу немає. Остання 0,5 с рухається, «заморожених» кадрів немає.

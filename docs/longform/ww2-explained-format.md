## 4. Що НЕ копіювати (ризики)

1. **12-секундне брендове інтро.** Для нового каналу це втрата глядачів у перші секунди. Hook — з першого кадру.
2. **Графічні кадри (тіла, крематорії) на початку.** Ризик вікового обмеження та обмеженої реклами. Показувати непрямо (паркан, табличка, порожній барак) або пізніше, з контекстом.
3. **Відео лише з чужої хроніки + озвучка.** Ризик політики YouTube щодо повторно використаного контенту (reused content) і відмови в монетизації. Потрібен власний сценарій з аналізом, власні карти/графіка.
4. **Права на хроніку.** Не вся архівна хроніка у public domain — перевіряти джерело і ліцензію кожного кліпу.
5. **40 хв → 10–15 хв.** Одне відео = одна тема. Розділи референсу стають окремими епізодами.

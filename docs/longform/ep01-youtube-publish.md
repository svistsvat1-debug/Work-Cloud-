## Порядок публікації

1. Завантажити відео → вставити назву, опис, теги.
2. Обкладинка → `ep01-thumbnail-flag-cross.jpg`.
3. Плейлист, аудиторія «не для дітей», категорія «Освіта», мова англійська.
4. Субтитри (SRT), кінцева заставка — зручніше в YouTube Studio на комп'ютері (studio.youtube.com): у мобільному застосунку частини функцій може не бути.
5. Опублікувати → одразу написати й закріпити коментар.

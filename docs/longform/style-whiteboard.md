# Стиль відео: Whiteboard-маркер (як Golpo) — наш стандарт для long-form

Статус: **прийнято 09.11.2026** — базовий візуальний стиль для довгих відео 16:9.
Референс: запис екрана відео "Dig through Earth? / Kola Superdeep Borehole" (стиль Golpo). Логотип Golpo **не** використовуємо.
Інструмент: `tools/whiteboard/` (див. README там). Усе робиться локально і безкоштовно.

## 1. Як виглядає кадр

| Елемент | Правило |
|---|---|
| Фон | Теплий папір / айворі `#F7F5EF`, ледь помітна текстура, без логотипів і водяних знаків |
| Ілюстрації | Маркерні дудли: товстий чорний контур, яскраві насичені кольори, видно штрихи маркера |
| Заголовки | Рукописний маркер (Permanent Marker), чорний, **червоне підкреслення** маркером |
| Акценти | Червоні стрілки з рукописними підписами, червоні кола-обведення, червоний хрест «✗», зелена галочка |
| Великі цифри/дати | Червоний маркер + синій підпис, **жовті «спалахи»** (короткі риски) з боків |
| Карти | Справжні контури (Natural Earth), обведені маркером, заливка штрихуванням; краї карти розчиняються |
| Цитати | Рукописний шрифт (Kalam), великі червоні лапки |
| Субтитри | **Немає** — текст на екрані лише як ключові слова/цифри |
| Палітра | ink `#1C1C20`, red `#E2242C`, blue `#1E68D6`, yellow `#FABC16`, green `#349E48`, orange `#F67E1C` |

## 2. Як рухається

- Кожен елемент **домальовується**: спершу чорний контур, потім кольорова штриховка «зигзагом».
- Текст пишеться зліва направо, підкреслення — після тексту.
- Елементи з'являються **синхронно зі словами озвучки** (таймінги з SRT).
- Нова сцена = нова думка: чистий аркуш, плавний перехід 0,3 с.
- Камера: повільний наїзд 3–8 % за сцену (на картах — до точки дії).
- Темп: новий елемент кожні 1–3 с, нова сцена кожні 5–20 с.

## 3. Ігрова механіка (для історичних відео)

- **MAIN QUEST** на старті (головне питання), розгадка у фіналі.
- Мапа рівнів: 5 кружечків-питань на пунктирній доріжці.
- Картка **QUESTION N/5** на початку кожного розділу, картка **ANSWER** у кінці.
- Картка **CLUE #N** + 3 слоти-ключі, які заповнюються по ходу.

## 4. Технічно

- 1920×1080, 30 fps, H.264 (crf 17), AAC 192k.
- Ілюстрації: локально SDXL + SDXL-Lightning (4 кроки, CPU bf16), стиль-промпт:
  `hand drawn doodle sticker, thick black outline, bright marker colors, white background, whiteboard animation style: <об'єкт>`
- Фон ілюстрацій вирізається автоматично, далі — анімація малювання нашим рушієм.
- Озвучка: готовий mp3 + SRT (наприклад, Kokoro `am_fenrir`), SRT дає таймінги сцен.

## 5. Що не робимо

- Логотипи/водяні знаки сторонніх сервісів.
- Субтитри на весь текст.
- Свастики й нацистську символіку крупним планом (ризик для монетизації); карикатури — без символів.
- Реалістичні «фейкові» фото подій — тільки стилізовані дудли.

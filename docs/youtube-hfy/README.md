# YouTube HFY — промпт для сценаріїв

[hfy-script-prompt.md](hfy-script-prompt.md) — один промпт, який вставляється в кожен новий чат і одразу видає готовий до озвучки сценарій (англійською, ~30–35 хв).

## Як користуватись

1. Відкрий новий чат з увімкненим веб-пошуком. Без нього модель не бачить, що зараз у тренді, і напише це в рядку TREND.
2. Встав промпт повністю. За бажанням допиши внизу, після `ALREADY PUBLISHED`, назви вже випущених відео.
3. Якщо текст обірвався на `[CONTINUE]`, напиши `continue`.

## Обмеження

- Чат не пам'ятає попередні чати. Унікальність тримається на свіжому пошуку трендів, випадковому виборі патерну і забороні типових ідей та імен. Гарантовано без повторів — тільки якщо вставляти список уже випущених назв.
- Модель рахує слова неточно: перевір лічильником (≈150 слів — це хвилина озвучки, залежить від голосу).

## Політика YouTube (перевірено пошуком 19.10.2026)

- Правило inauthentic content діє з липня 2025, у липні 2026 його уточнили. Серед прикладів порушень — персонажі знову і знову потрапляють у ту саму ситуацію з тим самим результатом. Тому в промпті жорсткі правила унікальності.
- Позначку AI-контенту ставлять при завантаженні. Для явно вигаданої анімації вона не потрібна. Щодо синтетичного голосу формулювання YouTube неоднозначне — якщо сумніваєшся, став позначку.

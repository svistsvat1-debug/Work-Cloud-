# YouTube HFY — промпт для сценаріїв

[hfy-script-prompt.md](hfy-script-prompt.md) — один промпт, який вставляється в кожен новий чат і одразу видає готовий до озвучки сценарій на ~20 хв (англійською, 3 000–3 300 слів).

Всередині — база і тренди поверх неї. База: 19 перевірених сюжетних двигунів, місця дії, герої, риси людей, формати оповіді, хуки, твісти, фінали, формули назв і приклади з твого зрізу. Тренди модель щоразу шукає через веб-пошук.

## Як користуватись

1. Відкрий новий чат з увімкненим веб-пошуком. Без нього модель працює тільки з бази і пише про це в рядку TREND.
2. Встав промпт повністю. За бажанням допиши внизу, після `ALREADY PUBLISHED`, назви вже випущених відео.
3. Якщо текст обірвався на `[CONTINUE]`, напиши `continue`.

## Обмеження

- Чат не пам'ятає попередні чати. Унікальність тримається на свіжих трендах, випадкових комбінаціях з бази і забороні типових ідей та імен. Гарантовано без повторів — тільки зі списком уже випущених назв.
- Модель рахує слова неточно: перевір лічильником. 3 000 слів ≈ 20 хв при ~150 слів за хвилину. Якщо голос читає швидше, збільш цифри в STEP 4.

## Політика YouTube (перевірено пошуком 19.10.2026)

- Правило inauthentic content діє з липня 2025, у липні 2026 його уточнили. Серед прикладів порушень — персонажі знову і знову потрапляють у ту саму ситуацію з тим самим результатом. Тому в промпті жорсткі правила унікальності.
- Позначку AI-контенту ставлять при завантаженні. Для явно вигаданої анімації вона не потрібна. Щодо синтетичного голосу формулювання YouTube неоднозначне — якщо сумніваєшся, став позначку.

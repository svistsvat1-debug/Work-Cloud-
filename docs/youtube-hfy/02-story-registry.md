# Story Registry — реєстр епізодів

Пам'ять системи для перевірки унікальності й ротації (розділ 9 майстер-промпту). Без актуального реєстру модель не знає, що вже було, і почне повторюватись.

Як вести:
1. Після `PACKAGE` встав сюди блок епізоду (нові — зверху) і онови файл у Project.
2. Через 7 днів після публікації допиши результати.
3. Запланований, але ще не опублікований епізод теж вноси (статус PLANNED), щоб наступні концепти з ним не перетинались.

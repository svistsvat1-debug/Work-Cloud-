# Trend Input — дані конкурентів (HFY)

Вхідні дані для команди `TRENDS`. Правила:
- Тільки реальні цифри, які ти бачив сам. Невідоме — `[MISSING]`.
- Новий зріз — зверху. Зрізи, старші за ~6 тижнів, переноси в «Архів» унизу (або видаляй), щоб модель орієнтувалась на свіже.
- Ratio = перегляди ÷ підписники. ≥10× — аутлаєр, ≥50× — сильний аутлаєр (робочий орієнтир, відкалібруємо).
- Додавай і відео, що НЕ зайшли (з тих самих каналів), — без них аналіз бачить лише переможців.

Як збирати — див. [README](README.md), розділ «Як збирати тренди».


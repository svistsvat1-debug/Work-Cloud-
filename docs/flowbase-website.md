# Flowbase — власний сайт (v1)

Код: `site/` (статичний сайт, без збірки). Тексти EN/UA/PL: `site/assets/js/i18n.js`, і тільки там (тут їх не дублюємо).
Бриф, за яким зроблено v1: односторінковий сайт, 6 блоків, EN за замовчуванням, без портфоліо, контакт тільки через повідомлення.

## Структура і логіка блоків

| # | Блок | Бізнес-задача | Ефект (у кожного блоку свій) |
|---|---|---|---|
| 1 | Hero | За 5 секунд: для кого ми, який результат, CTA «Message us» | Живий «потік» частинок на canvas (реагує на курсор), 3D-поява літер заголовка, parallax світлових плям, контент «відпливає» при скролі |
| 2 | Problem «Sound familiar?» | Відвідувач впізнає свої болі (5 штук з брифу) | «Хаос → порядок»: картки злітаються з різних боків, повернуті й розмиті, і складаються в рівний список під час скролу |
| 3 | Solution | Показати систему, а не «просто сайт»: Website → Lead → CRM → Automation → AI → Follow-up → Client | Блок закріплюється на екрані, лінія малюється, по ній їде «іскра», вузли загоряються по черзі, опис кожного кроку плавно змінюється |
| 4 | Services | 4 послуги; технічні терміни дозволені тут | 3D-перевертання карток при появі + нахил і золотий відблиск за курсором |
| 5 | Process | Знімає страх «а як це буде», підкреслює «без дзвінків» | Десктоп: горизонтальний скрол етапів з parallax-номерами. Мобільні: вертикальний таймлайн, лінія заповнюється при скролі |
| 6 | Final CTA | Заявка: форма + Telegram/WhatsApp | Фон розкривається колом від низу, заголовок проявляється слово за словом із розмиття, «магнітні» кнопки, анімована рамка форми |

Додатково: золота смужка прогресу скролу зверху, глобус-перемикач мов (вибір запам'ятовується, працює `?lang=uk` / `?lang=pl`).

Комфорт для відвідувача:
- анімації запускаються по мірі скролу, не всі одразу;
- `prefers-reduced-motion` → статична версія без руху (весь контент видно);
- без JS або якщо GSAP не завантажився → сайт теж повністю читабельний;
- canvas зупиняється, коли hero не на екрані або вкладка неактивна.

## Стек

- Чистий HTML/CSS/JS, без збірки → можна викласти на будь-який статичний хостинг (Netlify, Vercel, Cloudflare Pages, GitHub Pages).
- GSAP 3 + ScrollTrigger лежать локально в `site/assets/vendor/` (ліцензія GSAP — безкоштовна, включно з комерційним використанням), тобто CDN не потрібен.
- Шрифти: Manrope + Cormorant Garamond Italic (Google Fonts, з кирилицею й польськими літерами).

## Що треба заповнити перед запуском — `site/assets/js/config.js`

| Поле | Статус | Що потрібно |
|---|---|---|
| `formEndpoint` | [MISSING] | Сервіс, який пересилає заявки з форми на Gmail. Варіанти: Formspree або Web3Forms (обидва мають безкоштовний старт; ліміти перевірити на їхніх сайтах). Підключається одним рядком |
| `formAccessKey` | [MISSING, тільки для Web3Forms] | Access key з Web3Forms |
| `telegramUrl` | [MISSING] | `https://t.me/<username>` |
| `whatsappUrl` | [MISSING] | `https://wa.me/<номер>` |
| Домен | [MISSING] | Для хостингу і `og:url` |
| OG-зображення (прев'ю при пересиланні посилання) | [MISSING] | 1200×630, можна зробити пізніше |

Поки `formEndpoint` порожній, форма показує повідомлення «форма ще не підключена, напишіть у месенджер», а кнопки месенджерів неактивні.

## Як подивитись локально

```bash
cd site && python3 -m http.server 8000
# відкрити http://localhost:8000
```

## На що звернути увагу / ризики

- **Польські тексти** написані без носія мови. Перед запуском на PL-ринок варто дати вичитати носію.
- **UA-тексти на «ти»**, як у брифі (блок Problem). PL — теж на «Ty». EN — нейтральний «you».
- **Lead system самого сайту** поки мінімальна: форма → email. Наступний логічний крок для нашої ж «вітрини»: заявка → CRM + автоматична відповідь клієнту. Це сильний proof того, що ми продаємо (сайт сам показує систему в дії).
- Без кейсів довіру тримає тільки якість сайту і чіткість процесу. Коли з'являться перші проєкти — додати блок Proof (before/after) між Services і Process.

# Стиль-референс: «Marker Explainer» (розбір прикладу)

Джерело: запис екрана, 33 с (фрагмент відео 0:04–0:37 з 1:16), тема «Kola Superdeep Borehole».
Кадри для очей: `docs/video/style-ref/*.jpg`. Вотермарка `golpo` і плашка субтитрів у кадрах — від плеєра й сервісу, у наші відео вони **не** йдуть.

## Виміряно

| Що | Значення |
|---|---|
| Фон | рівний теплий білий, медіана `#FAF8F3` (RGB 250,248,243), без текстури й віньєтки |
| Камера | статична: 0 зумів, 0 панорам |
| Переходи | **жорстка склейка** на чисту дошку (9.8 с, 28.0 с), без витирання і фейдів |
| Склейка ↔ голос | склейка й нова дія починаються на паузі між реченнями (пауза 0.3–0.6 с, звук падає до ≈ −48 dB) |
| 1 речення = 1 візуальний біт | 4 речення → 4 біти: заголовок → головний об'єкт → підпис-стрілка → допоміжний об'єкт |
| Довжина сцени | 8–15 с (1–3 речення); об'єкти накопичуються, у межах сцени нічого не стирається |
| Темп голосу | ≈ 150–165 слів/хв, речення 10–20 слів, один факт на речення |
| Написання заголовка | ≈ 10–13 літер/с («Kola Superdeep» ≈ 1.0 с, «Borehole» ≈ 0.8 с) |
| Підкреслення | червоне, під **кожним словом окремо**, тягнеться одразу після слова |
| Малювання об'єкта | контур 0.4–0.8 с → заливка регіонами «скрибл-маскою» 2–3 с → деталі й стрілка 0.4 с; разом ≈ 4–5 с |
| Утримання кадру | після домальовування статика 2–5 с до наступного біта (це частина стилю) |
| Рука/олівець у кадрі | немає |
| Заповненість дошки | наприкінці сцени 10–30 % «чорнила», 70–90 % порожньо |
| Інтро | картка-обкладинка (3 рядки різнокольорового тексту + герой-об'єкт з «променями») під час хука, потім склейка |
| Звук | тільки голос, музики й SFX на слух не виявлено (у паузах майже тиша) |

## Палітра (виміряно, округлено)

| Роль | Колір |
|---|---|
| Контур / текст | `#111111` |
| Акцент №1 (підкреслення, стрілки, підписи, цифри) | червоний `#F0281E` |
| Гарячі тони заливки | `#F5541A` → `#F5781E` → `#F9A825` |
| Промені / іскри | жовтий `#FFCC1A` |
| Вторинний акцент (одиниці, «Earth?») | блакитний `#1EA0F0` |
| Океан / темно-синій | `#1673B8` |
| Суша / зелений | `#2E9E4A` |

## Композиція (частки кадру 16:9)

- Заголовок: зліва вгорі, x 2–22 %, y 4–20 %, 1–2 рядки, висота літер ≈ 5–6 % висоти кадру, легкий нахил вгору.
- Головний об'єкт: центр, ≈ 55–75 % висоти кадру.
- Підпис зі стрілкою: біля деталі, тонший червоний рукопис.
- Допоміжний об'єкт: праворуч, x 75–85 %, менший (≈ 40–50 % висоти), з жовтими рисками-променями.
- Числова картка: окрема сцена; число вгорі по центру, цифри червоні, одиниця блакитна, червоне підкреслення, по 3 жовті риски з кожного боку. Порядок: риски → цифри → підкреслення.

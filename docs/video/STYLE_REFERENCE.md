## Що робить стиль (розбір референсу)

| Елемент | Як зроблено |
|---|---|
| Форми | пласкі 2D-фігури без обведень; об'єм дають 2–3 тони, довгі тіні, підсвічений контур |
| Світло | сильне джерело (сонце, лампа, фари, вікно), силуети проти світла, кольорові тіні |
| Текстура | паперова текстура + плівкове зерно + віньєтка → картинка «тепла», не «корпоративний вектор» |
| Кольори | у кожній сцені одна цілісна палітра (3–5 тонів + темні); між сценами палітра змінюється за настроєм |
| Персонажі | спрощені пропорції, мінімум рис обличчя; багато історії через тіні, силуети, спини, руки |
| Композиція | кінематографічна 16:9, 3–5 шарів глибини, передній план-рамка (дерево, двері, проєктор) |
| Рух | камера весь час повільно рухається (наближення або зсув), шари з різною швидкістю, мінімальна анімація персонажів |
| Монтаж | новий кадр ≈ кожні 4–8 с (у референсі в середньому ~5,5 с), прямі склейки + перехід через затемнення |
| Звук | музика звучить постійно під голосом (у паузах звук не падає до тиші) |
| Хроніка | у референсі справжні кадри на екрані проєктора; **у нас ні**: правило 6, усе малюється кодом |

## Що можна кодом (перевірено тестом)

- Пейзажі, небо, світло, силуети, техніка, руїни, колючий дріт, дим, повільна камера з глибиною, зерно — так, на рівні тестового кадру.
- Персонажі з мімікою на рівні професійного аніматора — ні. Ставка на силуети, загальні плани, спини, руки й тіні.
- Продуктивність: не використовувати живі SVG-фільтри шуму на кожному кадрі. Зерно й текстура генеруються один раз або додаються у фінальному ffmpeg-кодуванні.

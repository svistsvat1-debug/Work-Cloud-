# A3. Packaging — "85 points"

## 5 назв (≤ 60 символів)

| # | Title (EN) | Символів | Форма (shape) і звідки |
|---|---|---|---|
| 1 ⭐ | **You Needed 85 Points to Leave WW2. Would You Make It?** | 53 | Гра від другої особи + число. Shape з "How Long Would You Survive in Every WW2 Job?" (EveryRank17, 131K, 2026-10-08). Тему й кінцівку змінено. |
| 2 | Why Millions of GIs Couldn't Go Home After WW2 Ended | 52 | "Why [група] [несподіване про дім] After the War". Shape з "Why Italian POWs Didn't Want to Go Home After the War" (BritishWarArchive, 145K). Інша група, протилежний сенс. |

Curiosity gap у кожній: число (85, 4, one point) або питання без відповіді. Слова конкурентів не копіювались.

## Thumbnail tactic transfer

- **Тактика конкурента (Ink Story):** великий everyman-солдат з екстремальною емоцією + **перевернуте очікування** ("війна → NO FIGHTING") + 2–3 слова.
- **Наша адаптація до сюжету:** очікування "війна скінчилась = додому" перевертаємо: **війна скінчилась, а він лишається**. Той самий тип героя (простий солдат-stick figure з великою емоцією), але намальований нашим маркером на білій дошці: товстий чорний контур, scribble-заливка olive/khaki, червоні стрілки, жовтий burst. Нічого з їхнього зображення не беремо.

## 3 концепції мініатюр (1280×720, marker whiteboard, фон #FAF8F3)

### Концепція 1 ⭐ — "ONE POINT SHORT" → пара з Title 1
```
┌──────────────────────────────────────────────────────────────┐
│  ONE POINT SHORT  (чорний маркер, червоне підкреслення,      │
│  жовті burst-штрихи)                       верх-праворуч      │
│                                                              │
│   [GI, по груди, 45% кадру]        ~~~~~~~ [КОРАБЕЛЬ] ~~~>   │
│   круглі очі, піт, рот "О",        відпливає праворуч,       │
│   olive-шолом                      дим, червона стрілка →    │
│   тримає картку:  ┌──────┐                                   │
│                   │  84  │  ← червоне велике число,          │
│                   │ /85  │    "/85" дрібно                    │
│                   └──────┘                                   │
└──────────────────────────────────────────────────────────────┘
```
- Об'єкти: солдат · картка 84 · корабель = **3**.
- Текст: "ONE POINT SHORT" (3 слова).
- Чому не повторює назву: назва каже "треба 85"; мініатюра показує **84 і корабель, що йде без нього**. Подвійний шок: число в назві → мінус один бал на картинці. У сценарії є момент "Eighty-four meant you stayed" (сцена 15), тож мініатюра чесна.

### Концепція 2 — "BACK TO WAR?" → пара з Title 2
```
┌──────────────────────────────────────────────────────────────┐
│  [банер "WELCOME HOME" над контуром Нью-Йорка]               │
│                                                              │
│   [GI з речмішком,          [квиток у руці:                  │
│    розгублений, піт]         "PHILIPPINES" + червона          │
│                              стрілка за край кадру]           │
│                                          BACK TO WAR?        │
└──────────────────────────────────────────────────────────────┘
```
- Об'єкти: банер зі скайлайном · солдат · квиток = 3. Текст: 3 слова.
- Деталь, якої немає в назві: 86-та дивізія повернулась у Нью-Йорк і була відправлена на Філіппіни.

### Концепція 3 — "NO BOATS, NO VOTES" → пара з Title 5
```
┌──────────────────────────────────────────────────────────────┐
│   [натовп stick-figures — 1 група, сірим]                    │
│        [GI спереду, сердитий,                                │
│         тримає плакат:  ┌───────────────────┐                │
│                         │ NO BOATS,         │ (червоний      │
│                         │ NO VOTES          │  маркер)       │
│                         └───────────────────┘                │
│                                 [конверт з червоним штампом] │
└──────────────────────────────────────────────────────────────┘
```
- Об'єкти: натовп · солдат з плакатом · конверт = 3. Текст = лише плакат (4 слова).
- Деталь, якої немає в назві: солдати-переможці **протестували** проти армії.

Безпека для всіх трьох: жодної нацистської символіки, жодної крові. Німеччина взагалі не потрібна на мініатюрі.

## Рекомендація

**Title 1 + Концепція 1:**
"You Needed 85 Points to Leave WW2. Would You Make It?" + солдат із карткою **84** і кораблем, що відпливає, текст **ONE POINT SHORT**.

Чому: назва ставить гру (85 і питання до глядача), мініатюра дає другий шок (84, мінус один бал), а хук відео — третій ("війна скінчилась, а тебе не відпускають").

Запасна пара для A/B-тесту (YouTube "Test & Compare"): Title 2 + Концепція 2.

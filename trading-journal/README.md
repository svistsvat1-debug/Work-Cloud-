# Edge Journal — торговий журнал (фаза 1, HTML)

Один файл `index.html`, без встановлення і без сервера. Відкрий у браузері (Chrome, Edge, Safari, Firefox).

## Як користуватись

1. Скопіюй скрін графіка (Win+Shift+S, Cmd+Ctrl+Shift+4, скрін на телефоні).
2. Натисни **Ctrl+V** на сторінці — відкриється нова угода зі скріном. **N** — нова угода без скріна.
3. Заповни інструмент, стратегію, результат, аналіз, що пішло не за планом, помилки й емоції. **Ctrl+Enter** — зберегти.

На телефоні: «Нова угода» → утримуй поле для скріну → «Вставити», або «Обрати файл».

## Що вміє

- Кілька скрінів на угоду, перегляд на весь екран, стиснення у WebP.
- Огляд: чистий P&L, вінрейт, profit factor, очікування, середній R, просідання, серії, крива капіталу, автоматичні висновки.
- Стратегії: порівняльна таблиця з сортуванням, P&L і очікування по кожній, правила стратегії як підказка у формі.
- Календар: денний і тижневий P&L, клік по дню — угоди цього дня.
- Аналітика: за планом / не за планом, ціна кожної помилки, дні тижня, години входу, інструменти, емоції, оцінка виконання, таймфрейми.
- Фільтри (період, стратегія, інструмент, напрям, результат, помилки, план, пошук) діють на всі вкладки.
- Експорт JSON (повна копія зі скрінами), імпорт JSON, експорт CSV для Excel.
- Демо-режим з прикладами, світла і темна тема.

## Де зберігаються дані

- **Локальний файл:** IndexedDB цього браузера. Не синхронізується між пристроями; очищення даних сайту видалить угоди. Роби експорт JSON.
- **Claude-артефакт:** приватний розділ користувача в сховищі артефакту (угоди) + сховище файлів артефакту (скріни). Доступно з телефона і комп'ютера.

Перенести дані: Налаштування → Експорт JSON на старому місці → Імпорт JSON на новому.

## Формули

- Вінрейт = прибуткові ÷ (прибуткові + збиткові), беззбиткові не враховуються (поріг беззбитку — у налаштуваннях).
- Profit factor = сума прибутків ÷ сума збитків. Очікування = чистий результат ÷ кількість угод.
- R = чистий результат ÷ ризик; якщо ризик не вказано — (вихід − вхід) ÷ (вхід − стоп) з урахуванням напряму.
- Чистий результат = результат − комісія.

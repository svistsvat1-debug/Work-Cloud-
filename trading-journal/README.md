# Edge Journal — журнал бінарних опціонів

Особистий торговий журнал. Основна версія — Claude-артефакт за посиланням: одна база для всіх пристроїв (записав на телефоні — бачиш на комп'ютері). Файл `index.html` — та сама програма, яка без Claude зберігає дані лише в браузері.

## Як заносити угоду

1. Скопіюй скрін графіка і натисни **Ctrl+V** на сторінці — відкриється нова угода зі скріном. **N** — нова угода без скріна.
2. Актив, ↑ Вгору / ↓ Вниз, стратегія, ставка, виплата %, експірація, результат: Плюс / Мінус / Повернення / Ще йде.
3. Аналіз, що пішло не за планом, помилки, емоції. **Ctrl+Enter** — зберегти.

Ставка, виплата, експірація і стратегія підставляються з попередньої угоди; виплата — з останньої угоди на цьому ж активі.
На телефоні: «Нова угода» → утримуй поле для скріну → «Вставити», або «Обрати файл».

## Що рахує

- Прибуток угоди: плюс = ставка × виплата %, мінус = −ставка, повернення = 0.
- Вінрейт = плюсові ÷ (плюсові + мінусові). Повернення не враховуються.
- Потрібний вінрейт = 1 ÷ (1 + виплата). При 85% це 54,1%. Перевага = вінрейт − потрібний, у п.п.
- Profit factor, ROI оборота (чистий результат ÷ сума ставок), середня угода, середня ставка, просідання, серії плюс/мінус.
- По стратегіях: вінрейт з рискою потрібного вінрейту, net, ROI, PF, найдовша серія мінусів, міні-графік.
- Календар днів і тижнів; аналітика: за планом / не за планом, ціна кожної помилки, «підняв ставку після мінуса», дні тижня, години, активи, експірації, емоції, розмір ставки.
- Висновки на «Огляді» пишуться автоматично з цих цифр.

## Дані

- **Артефакт:** приватний розділ користувача в сховищі артефакту (угоди) + сховище файлів артефакту (скріни, стискаються у WebP до 1920px).
- **Локальний файл:** IndexedDB браузера, без синхронізації.
- Перенести: Налаштування → Експорт JSON → Імпорт JSON. CSV — для Excel.

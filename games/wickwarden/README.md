# WICKWARDEN — браузерна survivor-гра (HTML5 Canvas + Vanilla JS)

Оригінальна гра в жанрі «bullet heaven / horde survival»: ти рухаєшся, зброя стріляє сама,
вороги сходяться з усіх боків, ти збираєш XP, обираєш апгрейди, б'єш босів, відкриваєш скрині й еволюціонуєш зброю.

- Без рушіїв і бібліотек: тільки HTML5 Canvas, Vanilla JavaScript (ES-модулі), CSS.
- Без зовнішніх асетів: вся графіка й звук генеруються кодом (canvas + Web Audio API).
- Внутрішня роздільність 1920×1080, масштабування під вікно зі збереженням 16:9.
- Усі спрайти персонажів і монстрів мають джерело 182×182 px; колізія — кола, значно менші за спрайт.

## Як запустити

ES-модулі не працюють через `file://`, тому потрібен будь-який локальний сервер:

```bash
cd games/wickwarden
python3 -m http.server 8000
# або: npx serve .
```

Відкрий http://localhost:8000. Також підходить розширення VS Code «Live Server».

## Керування

| Дія | Клавіші |
|---|---|
| Рух | WASD або стрілки (на тачскріні — тягни пальцем) |
| Вибір апгрейду | 1 / 2 / 3 або клік |
| Продовжити після скрині | Space / клік |
| Пауза | Esc або P |
| Здатися (на паузі) | Q |
| Звук вкл/викл | M або кнопка 🔈 |
| Debug-панель (FPS, лічильники) | F3 |
| Після смерті | R — рестарт, S — магазин, T — титул |

**Debug-режим** (для тестування): відкрий `index.html?debug`. Під час забігу:
`B` — боса, `C` — скриню поруч, `L` — +1 рівень, `X` — усі зброї на максимум + предмети для еволюцій,
`T` — +60 с до таймера, `H` — повне лікування.

## Структура

```
index.html, styles.css
src/
  main.js                     вхід: створює Game, масштабування 16:9, game loop з delta time
  config/
    GameConfig.js             усі числа: роздільність, гравець, вороги, бос, спавн, скейлінг, ефекти
    Weapons.js                зброя (data-driven, рівні 1–8) + еволюції
    Passives.js               пасивні предмети (рівні 1–5)
    Waves.js                  хвилі за часом
    MetaUpgrades.js           постійні апгрейди магазину
  core/
    Game.js                   state machine + володіє всіма системами й сутностями
    Input.js, Camera.js, MathUtils.js, SpatialGrid.js, Pool.js, Storage.js, StatModifiers.js
  entities/
    Entity.js (база) → Player, Enemy, Projectile, Pickup → XPGem, Coin; Chest
  systems/
    Spawner.js                wave director, боси, «оточення», перенесення відсталих ворогів
    WeaponSystem.js           поведінки зброї: projectile / orbit / pulse / strike
    CollisionSystem.js        колізії через spatial grid
    CombatSystem.js           шкода, смерть, дропи, game over
    UpgradeSystem.js          3 вибори на level-up + застосування
    ChestSystem.js            нагороди скрині й еволюції
    EffectsSystem.js          частинки, кільця, блискавки, цифри урону (з лімітами)
    AudioSystem.js            синтезовані звуки
    WorldMap.js               нескінченна мапа: тайл + декорації по чанках
    UISystem.js               HUD і всі екрани, кнопки на canvas
    Renderer.js               порядок малювання кадру, освітлення
  assets/
    ProceduralSprites.js      усі спрайти (182×182), іконки, декор, плитка підлоги
    MenuBackground.js         pixel-art фон меню (замок + лицар)
docs/                         дизайн-план, originality pass, баланс, промпт для фону
```

## Де що крутити

- Складність: `src/config/Waves.js` (інтервали, склад хвиль) і `scaling` у `GameConfig.js`.
- Швидкість прокачки: `xp` у `GameConfig.js`.
- Нова зброя: додай запис у `WEAPONS` з одним із 4 `behavior` — код не потрібен.
- Нова еволюція: додай рядок у `EVOLUTIONS`.
- Новий пасив / апгрейд магазину: запис у `Passives.js` / `MetaUpgrades.js`.
- Свій фон меню: поклади картинку в `assets/` і вкажи шлях у `GameConfig.menuBackgroundImage`
  (промпт для генерації — `docs/MENU_BACKGROUND_PROMPT.md`).

## Що перевірити вручну

1. Титул → Start → магазин → Begin Run. Консоль браузера (F12) без помилок.
2. Рух плавний, по діагоналі не швидший; гравець завжди в центрі, світ «їде».
3. Перші ~30 с спокійні, Ember Shot сам стріляє в найближчого ворога, при відсутності ворогів — чекає.
4. Геми притягуються, коли підходиш близько; XP-бар росте; level-up ставить гру на паузу, 1/2/3 працюють.
5. Дотик ворога: −HP, мигання, легкий screen shake, коротка невразливість.
6. На 1:00, 2:00, 3:00 … з'являється банер нової хвилі; на 2:00 — бос з великим HP-баром, перед ривком світиться червоним.
7. Бос лишає скриню → анімація (трясіння, спалах, нагорода), Space — продовжити.
8. `?debug`, `X` потім `C` → скриня дає «WEAPON EVOLVED!», у слоті зброї з'являється золота рамка й EVO.
9. Смерть → підсумок забігу; золото додається до загального; R / S / T працюють; після перезавантаження сторінки золото й покупки збереглися.
10. Магазин: купівля зменшує золото, ціна росте; Reset Save вимагає повторного кліку.
11. M вимикає звук, налаштування зберігається після перезавантаження.
12. Перемикання вкладки під час гри → автопауза.

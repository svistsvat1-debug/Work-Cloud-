# Wickwarden — дизайн-план (Prompt 1)

## 1. Core gameplay loop

```
рух → зброя б'є сама → вороги гинуть → падають XP-геми → збір → level-up (3 вибори)
  → сильніший білд → більше ворогів / швидші / міцніші → бос кожні 2 хв → скриня
  → апгрейд або еволюція зброї → … → смерть → золото в магазин → постійні апгрейди → новий забіг
```

Гравець керує лише рухом. Рішення гравця: куди рухатись (ухилятись / збирати геми) і що обрати на level-up.

## 2. Перший прототип (MVP)

- Canvas 1920×1080 з масштабуванням 16:9, game loop з delta time.
- Гравець (WASD/стрілки), камера в центрі на гравці.
- 2 типи ворогів (повільний / швидкий), спавн за межами екрана.
- Автоатака в найближчого ворога кожні 0.6 с, снаряди з шкодою.
- Kill counter + таймер виживання.

## 3. Структура файлів

Див. `README.md` → «Структура». Принцип: `config/` — тільки дані, `entities/` — об'єкти світу,
`systems/` — логіка, що працює над багатьма об'єктами, `core/` — інфраструктура.

## 4. Сутності

| Сутність | Ключові поля | Колізія |
|---|---|---|
| Player | x, y, vx, vy, health, level, xp, weapons[], passives[], stats | коло r=28 (спрайт 182 → 124 на екрані) |
| Enemy | type, health/maxHealth, speed, damage, knockback, flashTimer | коло 21–76 залежно від типу |
| Projectile | damage, pierce, knockback, hitIds | коло = size |
| XPGem | value → tier (blue 1 / green 5 / red 10), magnetized | коло 14 |
| Coin | value | коло 14 |
| Chest | позиція, світловий промінь | коло 36 |

Вороги: Inkling (повільний), Soot Moth (швидкий), Ash Tick (середній, менший хітбокс),
Smog Brute (танк), Snuffer Knight (еліта), The Wick-Eater (бос).

## 5. Система апгрейдів

- Level-up дає 3 випадкові варіанти з пулу: нова зброя / апгрейд зброї / новий предмет / апгрейд предмета.
- Пул будується з даних (`Weapons.js`, `Passives.js`), максимальні рівні не пропонуються.
- Ліміти: 4 зброї, 6 предметів. Якщо все на максимумі — фолбек «лікування» або «золото».
- Кілька рівнів за раз обробляються чергою (`pendingLevelUps`).

## 6. Система зброї

Кожна зброя = дані + одна з 4 поведінок:

| Поведінка | Зброя | Еволюція (+ предмет) |
|---|---|---|
| projectile — у найближчого | Ember Shot | Ember Tempest (+ Tallow Codex) |
| orbit — леза навколо | Ward Knives | Sunwheel (+ Kindling Stone) |
| pulse — коло навколо | Lantern Pulse | Dawnbreak (+ Ironwood Heart), лікує |
| strike — випадкові цілі на екрані | Storm Brand | Stormcrown (+ Lucky Wick), ланцюгова блискавка |

Рівні 1–8 задані таблицею бонусів. Еволюція: зброя lvl 8 + потрібний предмет + скриня → заміна зброї.

## 7. Хвилі ворогів

Таймлайн у `Waves.js`: 0:00 слизні → 1:00 + метелики → 2:00 + швидкі кліщі → 3:00 щільніше
→ 4:00 + танки → 5:00+ усі типи + еліта, далі інтервал продовжує скорочуватися.
Скейлінг HP / швидкості / шкоди від часу, ліміт 320 ворогів (спавн чекає, а не ламає гру).
Кожні 2 хв бос, кожні 60 с після 1:30 — «кільце оточення».

## 8. UI

- Верх: XP-бар на всю ширину, рівень.
- Зліва: великий HP-бар, слоти зброї (рівень / MAX / EVO), слоти предметів.
- Центр: таймер + назва хвилі; банери подій.
- Справа: кілли, золото, кнопка звуку.
- Низ: HP-бар боса; debug-панель (F3).
- Екрани: титул, магазин, level-up (3 картки), скриня, пауза, game over.

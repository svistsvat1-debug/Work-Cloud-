# Balance & performance pass (Prompt 16)

## Як міряли

- **Бот-симуляція**: бот у Chromium ухиляється від ворогів, збирає геми, обирає апгрейди випадково;
  гра крутиться з фіксованим dt = 1/60 без рендеру (швидше за реальний час).
- **Бос-тест**: бос на 2:00 проти типових білдів, гравець стоїть на місці.
- **Стрес-тест рендеру**: 320 ворогів, усі 4 зброї еволюціоновані, headless Chromium **без GPU**
  (програмна растеризація — найгірший випадок; на звичайному ПК з GPU запас більший).

Перед ривком бос 0.75 с світиться червоним і трясеться — від нього можна ухилитися.

## 2. Продуктивність

| Що зроблено | Ефект |
|---|---|
| Object pooling: вороги, снаряди, геми, монети, частинки, цифри | без сміття для GC у бою |
| Видалення мертвих об'єктів компактним проходом (без `splice`) | O(n) на кадр |
| Spatial grid для всіх колізій і пошуку сусідів | без перебору «кожен з кожним» |
| Кеш масштабованих спрайтів (джерело 182 → готовий розмір, з дзеркалом) | **28 → 45 FPS** у стрес-тесті |
| Освітлення / віньєтка рендеряться один раз, а не градієнтом щокадру | **45 → 52 FPS** |
| Ліміти: 320 ворогів, 450 частинок, 45 цифр, 320 гемів (далі злиття) | стеля навантаження |
| Відсічення об'єктів поза екраном при рендері | менше draw calls |

JS-час кадру в стрес-тесті: update ≈ 0.2 мс, render ≈ 2.4 мс; решта — растеризація.
Debug-панель (F3): FPS, вороги, снаряди, частинки, пікапи, позиція гравця.

## 3. Знайдені й виправлені баги

- Накладені additive-сяйва блискавок «засвічували» ділянки екрана в біле → менший розмір і прозорість.
- Hit flash повністю замінював спрайт: бос під вогнем ставав білим силуетом → напівпрозоре накладання, слабше для боса й еліти.
- Плитка підлоги 512 px з контрастними плитами давала помітну «сітку» → плитка 1024 px, менший контраст.
- Іконка золота в HUD відривалась від числа → позиція від ширини тексту.
- Клік по кнопці звуку на екрані скрині закривав скриню → виключено.

Перевірено автотестом: рестарт, game over від реальної смерті, пауза level-up, скриня й еволюція,
збереження/завантаження localStorage — помилок у консолі немає.
